# 스마트제조 코디네이터 자동 문서작성 시스템 — MVP PRD

## 목표와 사용자
코디네이터가 기업별 확인사실과 근거를 한 번 입력하고, 단계별 문안을 생성·검토·출력한다. 교육 CASE 4와 실제 고객사를 구분한다. 장비 구매가 아니라 제조문제 해결 흐름을 지원한다.

## 범위
- 로컬 웹앱, Python 3.12 표준 라이브러리 HTTP API, SQLite 영구저장, 한국어 반응형 화면. 문서작성·검증·전사문 요약은 API 키 없이 동작하며, 브라우저 음성인식이 없는 환경의 마이크 전사는 선택적으로 OpenAI Realtime API를 연결한다.
- 기업 여러 건 생성, 조회, 수정, 자료 백업. 공정·문제/원인·개선과제·H/W/S/W·제조데이터·KPI·사업비·공급기업·방문·구축상태를 하나의 프로젝트 모델로 관리한다.
- 각 사실은 값, 근거 ID, 사실구분을 갖는다. 확인사실, 분석, 진술, 추정, 목표, 미확정을 구분하며 교육사례 사실의 적용범위를 유지한다.
- 1차 수행일지+1차 현장진단표 → 2차 수행일지+2차 현장진단표 → 3차 수행일지+3차 현장진단표 → 사업계획서 → 결과보고서의 초안 생성. 공통필드 자동 반영, 근거 미비 시 지정된 보류표현 사용.
- 원본 HWPX를 업로드하고 XML 텍스트 위치를 문안 필드에 매핑한다. 템플릿 해시·기존문자 확인 후 복사본만 수정한다. 원본 보존, ZIP/XML 검사, 미매핑 경고, 한컴 최종 시각검수 안내를 제공한다.
- 구조화된 문서 스냅샷, 데이터 버전, 변경사유, 당시 상태를 보존한다. 과거 문서를 현재 실적으로 소급 변경하지 않는다.
- 숫자 근거, 단위/측정기간, 예산합계, 상태 근거, 관계 참조, 미래 완료일, 방문증빙, 원자료 상충, 문서 버전 불일치를 검증한다.
- 작업현황에서 한국어 대화를 실시간 전사하고 동시에 현장 메모를 작성한다. 전사 원문과 메모를 방문차수별 근거로 함께 저장하고, 두 내용을 통합한 규칙 기반 요약·분류 후 문제/원인/개선과제/H/W·S/W/제조데이터/KPI 후보를 사용자 진술로 자동 등록한다. 최근 전사 원문·메모·요약은 사용자가 검토·수정할 수 있으며 오디오는 서버에 저장하지 않는다.

## 비범위 및 경계
이번 MVP는 로컬 단일 사용자용이다. 인터넷 공개배포·다중 사용자 인증·AI 문안 자동생성·OCR·전자서명·사업신청 제출은 포함하지 않는다. OpenAI Realtime 연결은 음성을 텍스트로 변환하는 선택 기능에만 사용하고, 요약·분류·원장 반영은 로컬 규칙 엔진이 수행한다. HWPX XML 보존은 페이지 넘침이나 한컴 렌더링의 동일성을 보장하지 않는다. 예산의 지원 적격성이나 법령 준수는 현재 공고를 확인하기 전 확정하지 않는다.

## 화면흐름
작업현황 → 기업·근거 → 공정·진단 → 개선·설비 → 데이터·KPI → 사업비·공급기업 → 방문·상태 → 문서작성 → 일관성 검증 → HWPX 양식·출력.

작업현황은 KPI의 기준/목표/진술 실적을 나란히 보여주고, 다음 확인사항과 문서 진행을 우선 제시한다. 입력 화면에서 명시적으로 저장한다. 문안은 저장된 버전에서 생성되며 편집 후에는 새 버전을 생성한다. 원자료 상충은 별도 해결사유를 기록해야 해소한다.

## 수용기준
1. 재실행해도 기업 입력과 생성문서가 유지된다.
2. CASE 4 기준값 6, 목표 10, 사용자 진술 실적 10이 출처와 함께 표시된다. 측정기록이 없으면 객관적 성과달성으로 자동 판정하지 않는다.
3. 알 수 없는 값은 0으로 대체하지 않으며 네 가지 지정 보류표현으로 출력한다.
4. 검토/선정/발주/납품/설치/시범운영/운영/성과측정/성과달성을 구분하고 근거 없는 전이를 거부한다.
5. 5종 문서의 기업명·H/W/S/W·KPI·사업비는 동일한 스냅샷에서 가져온다.
6. 사업비는 현금지출(H/W+S/W 등)과 현물 포함 총사업비를 별도 비교한다.
7. HWPX 비대상 ZIP 구성파일 내용과 XML 구조를 보존하고 원본 해시 불일치, 중복 매핑, 예상 텍스트 불일치는 거부한다.
8. 웹 화면에서 입력 저장, 문안 생성, 검사결과 확인, 백업 및 출력까지 실행한다.
9. 브라우저 내장 음성인식 또는 서버 설정형 OpenAI Realtime 연결로 마이크 발화를 즉시 표시하고, 연결이 없으면 붙여넣은 전사문을 동일하게 요약·등록한다. API 키는 브라우저·DB·백업에 노출하지 않고, 발화 숫자와 상태는 확정 필드로 자동 반영하지 않는다.
10. PC와 같은 Wi-Fi의 모바일 기기는 실행 시 생성되는 접속 토큰으로 앱에 접근하고, 모바일 키보드 받아쓰기로 전사 입력칸을 채울 수 있다. 전사 원문·현장 메모·통합 요약의 수정 저장은 새 원장 버전으로 남는다.
