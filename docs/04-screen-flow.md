# 화면과 데이터 흐름

```mermaid
flowchart LR
 T[실시간 전사·요약·자동등록] --> A[기업·근거 입력]
 A --> B[공정·문제·원인]
 B --> C[개선과제·기능·H/W·S/W]
 C --> D[제조데이터·KPI·사업비]
 D --> E[방문정보·구축상태]
 E --> F[원장 저장·버전 생성]
 F --> G[1차 수행일지·현장진단표]
 G --> H[2차 수행일지·현장진단표]
 H --> I[3차 수행일지·현장진단표]
 I --> J[사업계획서]
 J --> K[결과보고서]
 K --> L[일관성 검증]
 L --> M[공식 HWPX 매핑·초안 출력]
 M --> N[한컴 배치·증빙 최종검토]
 L -->|추가확인| A
```

| 화면 | 주요 작업 | 저장 결과 |
|---|---|---|
| 작업현황 | 현재/목표/진술실적, 문서 준비상태 확인 | 조회 전용 |
| 실시간 전사 | OpenAI Realtime/브라우저 음성인식/직접 입력, 방문차수 선택, 요약·분류 | 전사 근거와 원장 새 버전 |
| 기업·근거 | 기업 입력, 증빙 위치, 사실구분 | 원장 새 버전 |
| 공정·진단 | 순서에 따른 공정 및 문제·원인 분리 | 공정·문제 ID 연결 |
| 개선·설비 | 기능·즉시개선·투자개선·도입설비 | 문제→과제→설비 연결 |
| 데이터·KPI | 수집부터 개선까지, 측정조건 | 데이터 ID→KPI 연결 |
| 사업비·공급기업 | 현금지출/현물/총사업비, 공급근거 | 예산 및 공급사 원장 |
| 방문·상태 | 당시 상태·면담·시간·증빙, 현재 상태전이 | 과거 기록 보존·변경사유 |
| 문서작성 | 순차생성, 이전 버전 조회, 문안 다운로드 | 불변 문서 스냅샷 |
| 일관성 검증 | 항목값 및 시점 차이, 상충 해결 | 저장 후 재검증 |
| HWPX 양식·출력 | 원본 업로드, 입력 위치 지정, 내보내기 | 원본 해시+매핑, 출력 감사기록 |

실행상태는 문서 차수와 별개이다. 3차 문서를 생성했다고 설치 상태로 이동하지 않는다. 결과보고서를 생성했다고 성과달성 상태로 이동하지 않는다.
